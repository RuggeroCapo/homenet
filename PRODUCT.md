# Product

## Register

product

## Users
Home-lab admin running Umbrel + OpenWrt + AdGuard Home. Checks network health at a glance, occasionally digs into a device or alert.

## Product Purpose
Self-hosted network watchdog and traffic analytics. Success: connectivity state and suspicious traffic are obvious in seconds.

## Brand Personality
Calm, precise, trustworthy. umbrelOS translucency with Linear-like restraint.

## Anti-references
Dense enterprise dashboards, neon "hacker" security tools, identical icon-card grids.

## Design Principles
1. Status first: health and alerts read before any chart.
2. Flat content, glass shell: blur only for navigation and floating layers.
3. One accent; colour otherwise means state.
4. Familiar patterns over invention.
5. Calm motion that conveys state only.

## Accessibility & Inclusion
WCAG AA contrast, visible focus rings, reduced-motion respected, status never colour-only.
